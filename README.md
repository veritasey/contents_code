# 조리기기 시뮬레이터 (Graphene Smart Cooker Simulator)

minMax 조리기기(그래핀 스마트 쿠커) 동작을 시뮬레이션하는 웹 데모입니다. 별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 구성

- `index.html` — 시뮬레이터 본체 (V8.2.0). 하나의 HTML 파일 안에 3개 화면(기기 LCD 패널 · 코어 엔진 & 하드웨어 상태 · 스마트싱스 모바일 앱 목업)이 준비되어 있고, 상단 메뉴로 4가지 보기 중 하나를 골라 볼 수 있습니다.
  - **🔲 기존 구성 (전체 보기)**: 3개 화면을 한 번에 보여줍니다. 동작 원리를 한눈에 파악하기에 좋습니다.
  - **🖥️ 기기 메뉴**: 식재료 카테고리 → 부위 → 굽기(조리 목표) 선택, 두께/초기 온도 테스트값 조정, 돌발상황 발생 시 짧은 상태 문구 표시만 단독으로 보여줍니다.
  - **⚙️ 코어 엔진**: 온도 센서, 조리 단계(대기 → 템퍼링 → 가열 → 레스팅), 히터 출력(PWM), 돌발상황 테스트 버튼, 로그를 단독으로 보여줍니다.
  - **📱 모바일 UX**: 스마트싱스 모바일 앱 목업만 단독으로 보여줍니다. 하단 탭으로 "기기제어"(굽기 개인화 피드백·골든타임 알림·돌발상황 안전모드)와 "서비스"(SmartThings 공기환경, Samsung Food 시즈닝 추천·재고, Samsung Health 웰니스 브리핑 진입 카드)를 오갈 수 있습니다.

  화면은 언제든 자유롭게 전환할 수 있고, 숨겨진 화면의 상태(입력값, 조리 진행 상황, 로그)는 그대로 유지됩니다.
- `docs/CHANGELOG.md` — 개발 과정에서 정리된 사양 변경 이력 (v6.0 ~ v8.2.0), 재료별 목표 온도표 포함

## 실행 방법

```bash
open index.html   # 또는 브라우저에서 파일을 직접 열기
```

## 참고

이 문서의 온도·시간 값은 실제 minMax DT 개발 과정에서 사람이 정리한 참고 수치이며, 공식 제품 사양이 아닙니다.
