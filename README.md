# 조리기기 시뮬레이터 (Graphene Smart Cooker Simulator)

minMax 조리기기(그래핀 스마트 쿠커) 동작을 시뮬레이션하는 웹 데모입니다. 별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 구성

- `index.html` — 시뮬레이터 본체 (V8.5.1). 하나의 HTML 파일 안에 3개 화면(기기 Device Setting 패널 · 코어 엔진 & 하드웨어 상태 · 스마트싱스 모바일 앱 목업)이 준비되어 있고, 상단 메뉴로 4가지 보기(📱 모바일 UX / 🔲 전체 구성 / 🖥️ 기기 메뉴 / ⚙️ 코어 엔진, 이 순서가 기본값) 중 하나를 골라 볼 수 있습니다.
  - **📱 모바일 UX** (기본 화면): 스마트싱스 모바일 앱 목업만 단독으로 보여줍니다. 재료·부위만 고르면 굽기·액세서리·시어링이 자동으로 채워져 "3탭 + 액세서리 확인 체크 1회"로 준비가 끝나고, 조리 시작은 기기 전용입니다 — 모바일 버튼은 건조기의 「건조기에 보내기」와 같은 **「조리기기에 보내기」** 패턴으로, 설정을 기기로 전송하는 데까지만 관여합니다(재료 미완료/액세서리 미확인/준비 완료/전송 완료 4단계 + 설정 변경 시 자동 무효화, 전송 완료 상태에서 1.5초 롱프레스로 데모 시작 가능). 조리 중에는 4단계 진행 표시·목표 온도·실제 시계 기준 완성 예정 시각·현재 동작(시어링 중 상단 그릴 접촉 안내 포함)을 보여주고, "자세히" 바텀시트에서 겉면 온도 등을 실시간으로 볼 수 있습니다. 완료 시 진동·알림음·토스트로 알려줍니다. 헤더에는 WiFi 연결 상태(오프라인 칩)가 표시되며, 하단 탭은 "기기제어"와 **"유용한 정보"**(SmartThings 공기환경, SmartThings Food 시즈닝 추천·재고, Samsung Health 영양·운동 추천, 다른 기기 레시피 변환, 조리 이력·가족 공유 — 6장, 롱프레스로 순서 변경 가능) 2개입니다. **조리 기기는 모바일 없이도 완결됩니다** — WiFi가 끊겨도 재료 선택부터 조리 완료·개인화 학습·조리 이력까지 전부 정상 동작하고, 가족 공유와 유용한 정보 카드 5장(조리 이력 카드 제외)만 막힙니다.
  - **🔲 전체 구성**: 3개 화면을 한 번에 보여줍니다. 동작 원리를 한눈에 파악하기에 좋습니다.
  - **🖥️ 기기 메뉴** (Device Setting): 식재료 카테고리 → 부위 → 굽기(조리 목표) 선택, 하단 용기·하단 그릴·상단(구리 그릴)·시어링 방식·시어링 간격 등 액세서리 구성, 두께/초기 온도/시어링 테스트값 조정, 돌발상황 테스트 버튼을 보여줍니다. 조리 중에도 잠금 오버레이 없이 패널 내용이 계속 보이고(선택 영역만 비활성화, 배속은 예외), 시작 버튼은 상태별로 4가지(조리 시작 / 중지 및 초기화 / 확인(초기화) / 안전모드 재개·중지)로 바뀝니다.
  - **⚙️ 코어 엔진**: 온도 센서(측정 두께 · 재료 온도 · 겉면 온도 · 소요 시간), 조리 단계(대기 → 템퍼링 → 가열/시어링 → 레스팅), 히터 출력(PWM) · 상단 그릴 승강, 돌발상황 테스트 버튼, 로그를 단독으로 보여줍니다.

  화면은 언제든 자유롭게 전환할 수 있고, 숨겨진 화면의 상태(입력값, 조리 진행 상황, 로그)는 그대로 유지됩니다. 실제 기기 화면 비율로 보고 싶다면 우측 하단 `📱` 버튼으로 전체화면(실기기) 모드를 켤 수 있습니다.
- `docs/CHANGELOG.md` — 개발 과정에서 정리된 사양 변경 이력 (v6.0 ~ v8.5.1), 재료별 목표 온도표 포함
- `test/verify_all.js`, `test/verify_device_mode.js` — jsdom 기반 자동 회귀 검증 (총 298개 항목)

## 실행 방법

```bash
open index.html   # 또는 브라우저에서 파일을 직접 열기
```

## 테스트

```bash
npm install        # jsdom 설치 (최초 1회)
npm test            # verify_all(267) + verify_device_mode(31) = 298개 항목
```

## 참고

이 문서의 온도·시간 값은 실제 minMax DT 개발 과정에서 사람이 정리한 참고 수치이며, 공식 제품 사양이 아닙니다.
